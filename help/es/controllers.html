    MIDI y Stream Deck

    Además del teclado, un presentador inalámbrico y el mando en el teléfono, PraiseAV se puede manejar con:

    • un pedal, teclado o controlador de pads MIDI: útil para quien dirige la alabanza tocando y quiere avanzar la letra por sí mismo
    • un Stream Deck (la caja de botones de Elgato), o Bitfocus Companion

    Haz clic en ⋯ Más, arriba a la derecha de PraiseAV, y luego en MIDI y Stream Deck….

    MIDI

    1. Conecta el aparato MIDI al ordenador (USB). Sirven un teclado con conexión USB, un pedal con una caja MIDI USB o un pequeño controlador de pads.
    2. Marca Usar MIDI. PraiseAV muestra los aparatos que ha encontrado.
    3. Para cada acción que quieras, haz clic en Aprender y pulsa la tecla, el pedal o el pad que quieras usar. Muestra lo que ha aprendido, por ejemplo Nota C4 (60) o Controlador 64.

    Las acciones: Siguiente, Anterior, Negro, Quitar texto, Logo, Notas ▶, ◀ Notas y Empezar el sermón.

    Haz clic en ✕ para olvidar una. PraiseAV recuerda las demás en este ordenador.

    Consejo: Un pedal de sustain conectado a un teclado envía Controlador 64: apréndelo para Siguiente y quien toca el teclado podrá avanzar la letra con el pie.

    Stream Deck

    La forma sencilla: hotkeys

    En la aplicación de Stream Deck, crea botones de tipo Hotkey con las teclas de PraiseAV:

    Botón Tecla
    Siguiente → (flecha derecha)
    Anterior ← (flecha izquierda)
    Negro B
    Quitar texto C
    Logo L
    Notas ▶ / ◀ Notas ] y [
    Activar o desactivar el vídeo en directo V

    PraiseAV tiene que ser la ventana de delante para que funcionen las hotkeys.

    Botones que siempre funcionan: direcciones web

    Cada acción también tiene una dirección web, que funciona aunque PraiseAV no esté delante, o desde otro ordenador con Bitfocus Companion.

    1. En MIDI y Stream Deck…, haz clic en Activar el control remoto si no está activado.
    2. Haz clic en Copiar junto a una acción para copiar su dirección.
    3. En la aplicación de Stream Deck, usa un complemento gratuito de web request de la tienda de Stream Deck (busca «web request») y pega la dirección en un botón. En Bitfocus Companion, usa el módulo Generic HTTP con una petición GET.

    Las direcciones llevan una clave secreta, así que solo tus botones pueden usarlas. Haz clic en Crear una clave nueva si crees que otra persona tiene las direcciones: las antiguas dejan de funcionar.

    Las direcciones copiadas empiezan por http://127.0.0.1, para un Stream Deck conectado al ordenador de PraiseAV. Para Companion en otro ordenador, usa la dirección que aparece en la ventana.
