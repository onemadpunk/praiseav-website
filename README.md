# praiseav.com

The PraiseAV website, published with GitHub Pages at https://praiseav.com.

- `index.html`: the home page
- `privacy.html`: the privacy policy (https://praiseav.com/privacy), linked from the app and the Microsoft Store listing
- `CNAME`: tells GitHub Pages the site's domain

Plain HTML, no build step: edit a file, commit and push with GitHub Desktop, and the site updates within a minute or two.
Keep the privacy policy in step with what PraiseAV does.
